## Computational Physics I

🔒 Part of this project is private.

This repository contains codes, simulations, and numerical experiments developed during the **Computational Physics I** course.

The main goal is to explore how computational methods can be used to solve physical problems that are difficult or impossible to approach analytically. Topics include numerical integration, differential equations, simulations, and data analysis applied to physical systems.

Furthermore, the exercises in Newman's book are open. The problem sets are closed, but will be gradually opened as the course progresses.
